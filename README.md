# ava

Meet Ava. She remembers things so you don't have to.

Ava is an agentic persistent memory Telegram bot which helps you to achieve your goals in life.
Replace your notes app!

Features:
1. Reminders - daily reminders scoped to long term goals
2. Memory - store information about anything, anyone - and retrieve it with natural language
3. Calendar - integrates into Google Calendar to save and remind yourself about events 
4. Personal GPT - search anything, conveniently from Telegram

LangGraph
Telegram Bot
Gemini Models
Postgres PGVector
